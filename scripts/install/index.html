bkt
The Bitbucket CLI · AVIO edition

Your Bitbucket workflow, in one CLI.

Built for developers and designed for AI agents. bkt brings Bitbucket Cloud and Data Center repositories, pull requests, pipelines, and AVIO's cleanup and access-management workflows into one command line.

Install from your terminal.

Install the latest stable release (the default), or opt into snapshot builds below. Choose your operating system and run the command in a terminal. Downloading bkt requires access to AVIO's private JFrog repository.

Linux

Run in a terminal with curl and sh.

x64
$ curl -fsSL https://tools.avio.dev/bkt.sh | sh

The installer prompts for your JFrog access token if JFROG_ACCESS_TOKEN is not already set. Open a new terminal after installation, then run bkt --help.

MacOS

Run in Terminal with curl and sh.

Apple Silicon · 13+
$ curl -fsSL https://tools.avio.dev/bkt.sh | sh

The installer prompts for your JFrog access token if JFROG_ACCESS_TOKEN is not already set. Open a new terminal after installation, then run bkt --help.

Windows

Run in PowerShell.

x64
PS> & ([scriptblock]::Create((irm https://tools.avio.dev/bkt.ps1)))

Windows uses a native x64 executable and requires PowerShell 5.1 or 7. No administrator access, Bash, Java, or Go installation is needed.

The installer prompts for your JFrog access token if JFROG_ACCESS_TOKEN is not already set. Open a new PowerShell window after installation, then run bkt --help.

Before you install

The bootstrap script is public, but the bkt package is stored in AVIO's private JFrog tools repository. You need a JFrog access token with read access to that repository. Enter it at the hidden prompt, or set JFROG_ACCESS_TOKEN in your environment. Do not paste tokens into shared commands.

Choose your install.

Stable follows the latest published release. Snapshot follows the latest published development build. Use a custom directory to choose where bkt is installed. Flags can be combined, for example snapshot plus a custom directory.

Linux and macOS

# Latest stable release (default; explicit selection shown)
curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel stable

# Latest snapshot
curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel snapshot

# Custom install directory (manage PATH yourself)
curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --bin-dir "$HOME/bin"

# Snapshot in a custom directory
curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel snapshot --bin-dir "$HOME/bin"

# Show installer usage without downloading a package
curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --help

--channel stable|snapshot selects the channel (default: stable). --bin-dir DIRECTORY changes the default ~/.local/bin directory and leaves PATH management to you. The default install adds the directory to your shell's PATH when needed. --help (or -h) prints usage. The sh -s -- syntax passes these flags to the downloaded script.

Windows PowerShell

Load the installer once, then run one of these examples. All examples install the native Windows x64 executable.

$installBkt = [scriptblock]::Create((irm https://tools.avio.dev/bkt.ps1))

# Latest stable release (default)
& $installBkt

# Explicit stable channel
& $installBkt -Channel stable

# Latest snapshot
& $installBkt -Channel snapshot

# Custom install directory (manage PATH yourself)
& $installBkt -BinDir "$HOME\bin"

# Snapshot in a custom directory
& $installBkt -Channel snapshot -BinDir "$HOME\bin"

# Show installer usage without downloading a package
& $installBkt -Help

-Channel stable|snapshot defaults to stable. -BinDir DIRECTORY changes the default %LOCALAPPDATA%\AVIO\bin directory and leaves PATH management to you. The default install adds the directory to your user PATH. -Help (or -h) prints usage. These are the installer's three parameters; PowerShell also supplies its standard common parameters.

After installation

Open a new terminal, run bkt --version to confirm the installed version, then bkt auth login to connect to Bitbucket Cloud or Data Center. Re-run an install command to update or change channel. Your Bitbucket login is separate from the JFrog token used to download bkt.
