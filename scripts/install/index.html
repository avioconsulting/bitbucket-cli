Your Bitbucket workflow, in one CLI.

Built for developers and AI agents. Manage repositories, pull requests, and pipelines across Bitbucket Cloud and Data Center, with AVIO's additional Cloud cleanup and access-management commands.

Install from your terminal.

One command installs the latest verified AVIO stable release by default. Native binaries, no Go toolchain required. The installer detects your platform and checks the download before installation.

Linux · x64macOS · Apple Silicon · 13+Windows · x64

Linux / macOS: latest release (default)

$ curl -fsSL https://tools.avio.dev/bkt.sh | sh

Run with curl and sh. The installer prompts for your JFrog access token unless JFROG_ACCESS_TOKEN is set. It installs to ~/.local/bin/bkt and adds that directory to your shell's PATH when needed. Rerun the same command to update.

Open a new terminal, run bkt --help, then bkt auth login to connect to Bitbucket.

Choose a channel: --channel

Use stable explicitly for the latest release, or snapshot for the latest development build. Rerun either command to update or switch channels.

curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel stable

Latest snapshot:

curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel snapshot

Custom install location: --bin-dir

The default is ~/.local/bin. With a custom directory, the installer does not modify your shell's PATH; add that directory yourself. Flags can be combined:

curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --channel stable --bin-dir "$HOME/bin"

Installer help: --help or -h

Show all installer options without installing or prompting for a token. -h is an alias for --help:

curl -fsSL https://tools.avio.dev/bkt.sh | sh -s -- --help

For a downloaded script, the equivalent short form is sh bkt.sh -h. In piped examples, sh -s -- passes the following flags to the installer.

Windows: PowerShell installer

& ([scriptblock]::Create((Invoke-RestMethod https://tools.avio.dev/bkt.ps1)))

Use Windows PowerShell 5.1 or PowerShell 7 on Windows x64. No administrator access, Bash or Go installation is needed. The installer prompts securely for a JFrog token unless $env:JFROG_ACCESS_TOKEN is set. It installs bkt.exe into %LOCALAPPDATA%\AVIO\bin and adds that directory to your user PATH. Stable is the default; rerun to update.

Latest Windows snapshot:

& ([scriptblock]::Create((Invoke-RestMethod https://tools.avio.dev/bkt.ps1))) -Channel snapshot

Optional custom directory (manage PATH yourself):

& ([scriptblock]::Create((Invoke-RestMethod https://tools.avio.dev/bkt.ps1))) -Channel stable -BinDir "$HOME\bin"

Append -Help to show options without installing, downloading artifacts or prompting for a token. You can also download bkt.ps1, inspect it, and run .\bkt.ps1 -Help.

Before you install

The installer is public; binaries are in AVIO's private JFrog tools repository. Use a JFrog access token with read access, entered at the hidden prompt or supplied through JFROG_ACCESS_TOKEN in the installer's environment. This token is separate from your Bitbucket login.
